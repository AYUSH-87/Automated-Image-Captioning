System Architecture & Pipeline

Merge Architecture

The system separates visual perception from sequence generation, merging them into a unified multimodal decoder layer:

Image ──► InceptionV3 (299×299) ──► Dense(256) ──► Dropout ──┐
                                                             ├──► Add ──► Dense(256) ──► Softmax(Vocab)
Text  ──► Embedding(256) ───────► Dropout ──► LSTM(256) ─────┘

Decoding Strategy

Uses Greedy Decoding with startseq initiation and endseq termination. Each step samples the highest probability token from the vocabulary distribution.

Hardware & Performance

  • In-memory model weights pre-loaded to minimize cold-start latency.
  • Zero disk writes during inference: inputs are read directly from memory streams.
  • Global Average Pooling eliminates spatial parameter bloat, keeping memory footprint low.
